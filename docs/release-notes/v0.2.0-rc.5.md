BatCave 0.2.0-rc.5 updates the monitoring UI and fixes macOS network attribution on newer systems.

- Overview and Explore now use consistent app identities, history, and data-quality states.
- Disk and network rates stay on separate, stable lines as the values change.
- macOS qualifies the available network interface at runtime instead of rejecting newer Darwin versions. Missing metrics remain visible as unavailable.
- Local history is bounded, persistence runs outside the sampling path, and hidden inspectors stop requesting detail.
- Windows collector service upgrades and CPU-source authentication handle failure and recovery more consistently.
- The README, documentation, and native app screenshots reflect the current UI.

This is a preview. The measured macOS CPU and memory usage still exceeds the project's performance targets. Oldest-supported-system and full installed lifecycle verification remain open. macOS kernel CPU is unavailable, and QUIC attribution has not been separately verified. Prereleases are not offered by the stable in-app updater.
