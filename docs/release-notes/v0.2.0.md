BatCave 0.2.0 is the first stable release of BatCave Monitor, a local resource monitor for Windows, Linux, and Apple Silicon Macs.

- See machine-wide CPU, memory, disk, and network activity beside the apps and processes using them.
- Rank grouped apps and individual processes by CPU, memory, disk, network, or activity. Rankings use 5-second averages, and new processes join after 3 seconds, so the list stays steady while values update.
- Inspect a process or group with its recorded history for every resource, even after it leaves a filtered view.
- Filter to workloads that are busy now or moving data, and see whether each measurement is native, estimated, limited, or unavailable. Missing telemetry is never shown as zero.
- Per-process network activity comes from XNU NStat on macOS, ETW on Windows, and optional eBPF probes on Linux.
- Telemetry stays on the machine: no analytics, uploads, or remote logging.

Changes since 0.2.0-rc.6:

- History for running workloads is no longer released under memory pressure; the oldest samples are trimmed evenly instead.
- The inspector's CPU, memory, disk, and network charts line up.
- Rows that leave a filtered view while the list is held read "Left view" instead of "Exited".
- Process icons load in filtered views, macOS icons match Finder and the Dock, helper processes use their app's icon, and icons fill their tiles.
- Dependencies are refreshed, including a fix for the devalue advisory.

Oldest-supported-system verification and the full installed Windows lifecycle proof remain open. macOS kernel CPU is unavailable, and QUIC attribution has not been separately verified.
